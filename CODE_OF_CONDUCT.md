# Code of Conduct

Be kind, assume good intent, and keep feedback about the work, not the person.

Harassment, insults, and personal or political attacks aren't welcome in issues, pull requests or discussions. Maintainers may edit or remove comments and block people who don't follow this.

Report problems privately to the maintainer through their GitHub profile ([@FlutterSmith](https://github.com/FlutterSmith)). Reports are handled confidentially.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
